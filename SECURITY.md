# Security Policy

## Supported Versions

Critical security patches and vulnerability remediation are actively maintained for the current repository baseline.

| Version | Supported |
| :--- | :--- |
| Main (HEAD) | Yes |
| Tagged Releases | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information exposure within this repository, do not open a public issue.

Please report vulnerabilities privately via email:

- **Contact**: `atacanymc@gmail.com`
- **Subject Line**: `[SECURITY] aws-saa-c03-notlari vulnerability report`

### Remediation Process

1. **Initial Response**: Within 48 hours of receipt, acknowledging the vulnerability report.
2. **Impact Assessment**: Evaluation of severity, attack vector, and affected assets.
3. **Remediation & Patching**: Development and validation of a fix.
4. **Public Disclosure**: Coordinated release following confirmation that the patch is in place.
